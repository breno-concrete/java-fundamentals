## Onde cada assunto do ROADMAP costuma cair

| Assunto | Baralho |
|---|---|
| equals/hashCode, contratos de `Object`, encapsulamento, herança vs composição | `JAVA::OO` |
| records, enums, imutabilidade, classes aninhadas, construtores | `JAVA::Classes` |
| `HashMap`, `ArrayList`, `TreeMap`, custos das coleções na API do Java | `JAVA::Collection` |
| generics, wildcards, PECS | `JAVA::Generics` |
| lambdas, streams, `Optional` funcional | `JAVA::Lambda` |
| Spring (IoC, AOP, transações, MVC, Security), JPA/Hibernate | `JAVA::SPRING` |
| padrões de projeto, SOLID, coesão/acoplamento | `JAVA::Arquitetura` |
| estrutura de dados implementada à mão (hash map próprio, array dinâmico) | `DSA::EDA` |
| LeetCode de arrays e hashing, two pointers, sliding window | `DSA::ARRAYS` |
| LeetCode de pilha/fila, listas, árvores, busca, ordenação | subdeck correspondente de `DSA` |
| SQL, modelagem, índices, transações, isolamento | `SQL` |
| Docker, Compose, imagens | `DOCKER` |
| JUnit, Mockito, estratégia de testes | `Testes de Software` |
| arquitetura hexagonal, Clean Architecture | `System Design::Clean Architecture` |
| escala, cache, filas, entrevistas de system design | `System Design` |
