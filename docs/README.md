# docs/ — guia da linha de aprendizado

Documentos que guiam o plano de estudos e que o Claude lê antes de ajudar.
Código fica em `src/`, anotações pessoais em `notes/`, LeetCode em `leetcode/`.

| Arquivo | Para quê | Quem atualiza / quando |
|---|---|---|
| [ROADMAP.md](ROADMAP.md) | Plano de 52 semanas (Caminho das Pedras): matérias, metas mensais, semana a semana, regras da casa | Só muda quando o plano desloca (regras 3, 4, 8) |
| [weeks/week-NN.md](weeks/) | Plano detalhado da semana, dia a dia, com checkboxes | Criado no domingo a partir do ROADMAP · marcado durante a semana |
| [learner/PROFILE.md](learner/PROFILE.md) | Quem é o Breno, o que já sabe, como ensinar | Quando algo muda no contexto (estágio, faculdade, projetos) |
| [learner/PROGRESS.md](learner/PROGRESS.md) | Estado atual: semana, deslocamento do plano, notas das provas de fase, lacunas abertas | Todo domingo e depois de cada prova de fase |
| [learner/DIAGNOSTIC.md](learner/DIAGNOSTIC.md) | Perguntas do diagnóstico (4.1a, 4.2a…) e nota por área | No checkpoint (Abr/2027) e no fim (Out/2027); marcar quando conseguir explicar sem consultar |
| [PARKING-LOT.md](PARKING-LOT.md) | Assuntos novos que apareceram fora de hora (regra 5, FOMO) | Sempre que surgir um; revisar no fim de cada matéria |
| [books/](books/README.md) | Livros de referência (PDF/EPUB só localmente) e índice com as semanas em que cada um entra | Ao baixar um livro · marcar ✅ no índice |
| [exams/](exams/) | Resultado de cada prova de fase (`phase-NN-<materia>.md`) | Na semana marcada `Phase exam` |
| [templates/](templates/) | Modelos para semana, notas e prova de fase | Raramente |

## Ritual semanal (domingo)

1. Atualizar `learner/PROGRESS.md` (semana que passou, o que ficou pendente).
2. Criar `weeks/week-NN.md` a partir de `templates/week-plan.md` e da seção da semana no ROADMAP.
3. Criar `notes/weekNN.md` a partir de `templates/week-notes.md`.
