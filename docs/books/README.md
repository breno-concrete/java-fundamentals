# Livros de referência

Os arquivos dos livros (PDF/EPUB) ficam nesta pasta **só localmente**: o `.gitignore` deixa de fora tudo daqui menos este índice (direitos autorais e tamanho).
O Claude lê os PDFs direto daqui (por intervalo de páginas), então prefira PDF com texto selecionável.

**Nome do arquivo:** `kebab-case` do título, ex.: `effective-java-3e.pdf`.
