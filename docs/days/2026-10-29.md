## Caderno de erros

| Passo | Erro | Causa | Conceito |
|---|---|---|---|
| 1.0 | Nó com `next`, `prev` e valor; sem a chave | Pensou em lista duplamente encadeada genérica. Sem a chave, o `equals` não tem com o que comparar numa colisão; o `prev` não é usado | Nó do bucket = key, value, next |
| 1.0 | Tipou `key` e `value` como `String` | O `<K, V>` existe justamente para o mapa servir para qualquer tipo; o nó usa `K` e `V` | Generics |
| 1.0 | Não sabia como fazer "ponteiro" em Java | Todo campo de tipo objeto já é uma referência: `Node<K, V> next` | Referências em Java |
| 1.0 | Achou que `static` = "usado só dentro da classe" | Isso é `private`. `static` numa classe aninhada = não carrega referência escondida para o objeto de fora | `static` vs `private` |
| 1.0 | Criou campos `Object keyType` / `Object valueType` para "guardar o tipo" | Tipo genérico não é campo: é parâmetro da classe (`<K, V>`), resolvido pelo compilador | Generics: parâmetro de tipo |
| 1.0 | Nó como classe separada "para reusar em outras estruturas" | O nó do mapa é específico (tem chave e valor) e é detalhe interno; reuso aqui vaza a implementação | Classe aninhada `private static` |
| 1.1 | Teste "devolve null" com `assertEquals(1, key)`; método `getKey` e variável `key` | Confundiu o que entra (chave) com o que sai (valor); a asserção contradizia o nome do teste | `get(key)` devolve o valor; `assertNull` |
| 1.2 | `get` checou `buckets[idx].value == null` em vez de `buckets[idx] == null` → NPE no mapa vazio | Checou o campo do nó, mas o que é `null` no bucket vazio é o próprio nó; ler `.value` de `null` já explode | Bucket vazio = `null`; checar a referência antes de usar |
| 1.3 | Escreveu o código antes do teste, e o teste de sobrescrita não verifica o `size` | Teste escrito depois nunca foi visto vermelho; e justamente a metade da lacuna (size não aumenta) ficou sem asserção | Test-first: ver o vermelho prova que o teste testa algo |
| 1.3 | Comparou chaves com `==` no `put` | `==` compara referência (mesmo objeto); passa com `Integer` 2 por causa do cache (-128..127) e falha com 1000. Chave se compara com `equals` | `==` vs `equals`, cache de `Integer` |
