## Fase 3 · Modelo de domínio, test-first (~45 min)

As três entidades. **Entidades se comparam pelo id**: dois objetos com o mesmo id são a mesma coisa, mesmo com outros campos diferentes (o mesmo princípio dos Items 10–11 da semana 1; seu `Member` de `labs/week01` é uma referência).

- [ ] `Member` (id, nome). Teste primeiro: dois `Member` com o mesmo id e nomes diferentes são `equals` e, num `HashSet`, contam como 1. Vermelho, verde
- [ ] `Event` (id, tipo, data). O tipo é um de 3 valores fixos (ensaio, culto, show): um `enum`. Se for novo, o tutor mostra o como com um exemplo antes. Teste de igualdade pelo id
- [ ] `Attendance` (o membro, o evento, se confirmou, se chegou, minutos de atraso). Pergunta de design antes de escrever: qual é a "identidade" de uma presença? Ela precisa de um id próprio, ou é o par membro + evento?
